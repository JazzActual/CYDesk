Install CYDesk

Pick the size on the back of the board. Both are plain ESP32s, so the page cannot tell them apart.

  1. Use Chrome, Edge, or Firefox on a computer. Phones and Safari can't see the USB port.
  2. Plug the board in with a data USB cable. A charge-only cable will not show a port.
  3. These boards use a CH340 USB chip. Install that driver before you look for a port, then unplug the board and plug it back in.
    • Windows: run CH341SER.EXE from the WCH driver page.
    • Mac: install CH341SER_MAC.ZIP from that same page. If macOS asks, allow the driver under System Settings → Privacy & Security.
    • Linux: the driver is already in the system. Nothing to install.
  4. Click the button for your size and choose the port. After the driver is in, it usually says USB Serial, usbserial, or wchusbserial. If the list is empty, the driver or the cable is the problem.
  5. On the erase question, leave Erase device unchecked. Check it only if you want a blank board. That clears the saved Wi-Fi and keys.
  6. When the screen is up, join the Wi-Fi network CYDesk and pick your home network. It has to be 2.4 GHz.
  7. Open the address shown on the screen and add your name, ZIP code, WeatherAPI key, and WDGWars key. Those stay on your board.

2.8 inch

E32R28T / ESP32-2432S028. 240×320.

This browser can't install to the board. Use Chrome, Edge, or Firefox on a computer. This page was opened as a file, so the browser won't allow USB. Serve the folder and open http://localhost:8000.

3.5 inch

ESP32-3248S035R, the resistive one. 320×480. The capacitive board (the one ending in C) uses a different touch chip.

This browser can't install to the board. Use Chrome, Edge, or Firefox on a computer. This page was opened as a file, so the browser won't allow USB. Serve the folder and open http://localhost:8000.

Installing the wrong size will not damage the board. The picture will look wrong until you install the matching one.

To open this page on your own computer, in the flasher folder run python3 -m http.server and visit http://localhost:8000. pio run rebuilds the 2.8" file. pio run -e cyd35 rebuilds the 3.5" file.
