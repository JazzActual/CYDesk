Install or update CYDesk

Same button for a blank board and for one that already runs CYDesk. Pick the size on the back — these are plain ESP32s, so the page cannot tell them apart.

Updating an already-flashed board? Plug it in, pick the matching size, click the button, and leave Erase device unchecked. That keeps the saved Wi-Fi network and API keys. Check Erase only when you want a blank board.
  1. Use Chrome, Edge, or Firefox on a computer. Phones and Safari can't see the USB port.
  2. Plug the board in with a data USB cable. A charge-only cable will not show a port.
  3. These boards use a CH340 USB chip. Install that driver before you look for a port, then unplug the board and plug it back in.
    • Windows: run CH341SER.EXE from the WCH driver page.
    • Mac: install CH341SER_MAC.ZIP from that same page. If macOS asks, allow the driver under System Settings → Privacy & Security.
    • Linux: the driver is already in the system. Nothing to install.
  4. Choose your board in the list below, click Install or update, and pick the port. After the driver is in, it usually says USB Serial, usbserial, or wchusbserial. If the list is empty, the driver or the cable is the problem.
  5. When the dialog asks about erase: leave Erase device unchecked to keep settings. Check it only for a factory-clean flash.
  6. First install only: when the screen is up, join the Wi-Fi network CYDesk and pick your home network (2.4 GHz). Open the address on the screen and add your name, ZIP, WeatherAPI key, and optional account keys.

Board

E32R28T / ESP32-2432S028. 240×320.

This browser can't install to the board. Use Chrome, Edge, or Firefox on a computer. This page was opened as a file, so the browser won't allow USB. Serve the folder and open http://localhost:8000.

Installing the wrong size will not damage the board. The picture will look wrong until you install the matching one.

After this firmware is on the board and it is on your Wi-Fi, you can also update over the network with PlatformIO (espota) — see the Firmware section on the desk's settings page at http://cydesk.local.

To open this page on your own computer, in the flasher folder run python3 -m http.server and visit http://localhost:8000. pio run rebuilds the 2.8" file. pio run -e cyd35 and pio run -e cyd40 rebuild the taller boards.
